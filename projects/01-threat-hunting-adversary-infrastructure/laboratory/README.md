# Threat Hunting Laboratory

## Exercício

1. Definir um indicador inicial.
2. Formular uma hipótese.
3. Pesquisar certificados relacionados.
4. Correlacionar domínios, IPs e ASN.
5. Avaliar DNS e serviços.
6. Analisar PCAP quando disponível.
7. Extrair IOCs.
8. Mapear TTPs.
9. Registrar evidências.
10. Produzir o relatório.

## Checklist

- [ ] Ambiente autorizado
- [ ] Hipótese registrada
- [ ] Evidências coletadas
- [ ] Infraestrutura correlacionada
- [ ] IOCs extraídos
- [ ] TTPs documentadas
- [ ] Evidências sanitizadas
- [ ] Relatório concluído
