# Attribution Laboratory

## Objetivo

Praticar atribuição sem transformar um único IOC, TTP ou ferramenta em prova conclusiva.

## Exercício

1. Selecionar uma campanha documentada publicamente.
2. Definir a intelligence requirement.
3. Criar pelo menos duas hipóteses alternativas.
4. Coletar evidências independentes.
5. Classificar as evidências pelos Six Signals.
6. Aplicar o raciocínio do Q Model.
7. Considerar evidências favoráveis e contrárias.
8. Avaliar confiança.
9. Registrar intelligence gaps.
10. Produzir o relatório.

## Checklist

- [ ] Pergunta definida
- [ ] Hipóteses alternativas
- [ ] Evidências independentes
- [ ] Six Signals preenchidos
- [ ] Q Model analisado
- [ ] Evidências contraditórias consideradas
- [ ] Confiança justificada
- [ ] Limitações registradas
